# Criminal Occurrences Dashboard - RIDE-DF Region

Interactive dashboard analyzing crime data across municipalities in the Integrated Development Region of the Federal District and Surroundings (RIDE-DF), Brazil, covering 2022-2024.

🔗 **[Live Dashboard](https://dashboard-ocorrencias.streamlit.app)**

**Language Note:** Dashboard interface is in Portuguese (PT-BR) for local law enforcement and policymakers.

## 📊 About

Real-time visualization of criminal occurrences in the RIDE-DF metropolitan region, enabling pattern analysis and trend identification across different municipalities and crime types.

## 🛠️ Technologies

- Python
- Streamlit
- Pandas
- Plotly

## 📅 Data Coverage

2022 - September 2024
